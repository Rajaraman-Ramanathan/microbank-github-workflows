# GitOps Policy Validation

Validates rendered Kubernetes manifests against the central
Microbank platform policy set.

## Purpose

The action provides shift-left policy validation for GitOps pull
requests.

It validates manifests generated by `gitops-helm` before the
GitOps change is merged.

The action does not:

- deploy resources
- access an EKS cluster
- replace Kyverno admission enforcement
- allow the service repository to define its own platform policies

## Inputs

### `rendered-directory`

Directory containing manifests generated by `gitops-helm`.

Default:

```text
.gitops-rendered
