# GitOps Kubernetes Validation

Validates rendered Kubernetes manifests generated by the
`gitops-helm` action.

## Purpose

The action validates generated Kubernetes manifests against the
specified Kubernetes API schema.

It does not:

- access an EKS cluster
- authenticate to AWS
- apply resources
- invoke Argo CD
- perform runtime validation

## Inputs

### `rendered-directory`

Directory containing manifests generated by `gitops-helm`.

Default:

```text
.gitops-rendered
